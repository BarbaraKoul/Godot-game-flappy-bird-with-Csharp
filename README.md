# Flappy Bird game made in Godot Engine using C#

<img width="869" height="942" alt="Screenshot of the game" src="https://github.com/user-attachments/assets/1600361e-dea7-4b27-948e-574a65a34c41" />

This is the game I developed for one of the meetings in the game development team in IEEE NTUA SB CS Chapter in Godot Engine using C#.

## Features and Gameplay
- **Bird:** It flies (moves upwards) via left click.
- **Game Over:** If the bird collides with a pipe or the ground, a Restart Button appears.
- **Score:** Every time the bird passes a pipe, the score increases by 1.

## How to Run/Play the game
- Clone the Repository: ``` bash git clone <https://github.com/BarbaraKoul/Godot-game-flappy-bird-with-Csharp>```
- Open **Godot Engine** and click **Import**
- Navigate to the cloned folder and select the ```project.godot``` file
- Press **F5** to run the game or export it for your OS!
